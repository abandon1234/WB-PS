# 自定义字体目录

把 `.ttf` / `.otf` / `.ttc` / `.otc` 字体文件放进这个目录，工具就会把它们
和系统字体一起列入「字体」下拉框，可直接用于文字替换。

## 两种添加方式

1. **界面上传**：编辑面板 → 字体 → 「导入字体」，选文件即可，立即生效，不用重启服务。
2. **手动放置**：把字体文件拷进本目录，然后点「重新扫描」（或重启服务）。

## 说明

- 本目录优先级高于系统字体。若字体族名与系统字体重名，会优先使用这里的版本。
- `.ttc` / `.otc` 是字体集合，内含多个字体，会自动逐个登记。
- 删除字体文件后同样需要「重新扫描」才会从列表里消失。
- 本目录内的字体不会随代码提交（已在 `.gitignore` 中排除），
  以免把有版权的商业字体分发出去。
