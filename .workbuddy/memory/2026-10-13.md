# 2026-10-13

## 生成工具四合一（commit 26ef277）

用户要求：把侧栏的四个生成工具（自由生成 / 图像融合 / 人物写真 / 商品图生成）
融合成一个；并说明**生图 API 已失效，不要做生成测试**。

做法：合并为单一工具 `generate`（名称「AI 生成」），语义由「有没有传参考图」决定 ——
不传 = 纯文生图（提示词原样发送），传 1~4 张 = 以参照图主体为准生成。
原来四种玩法的差异改由提示词表达，chips 里给了对应例子。

改动点（也是下次改这块的入口清单）：

- `web/shell.js`：NAV 收敛为 无痕改字 / AI 生成 / 作品库；`LEGACY` 表把老 hash
  （create/combine/portrait/product）映射到 generate，侧栏高亮不丢。
- `web/image.js`：`TOOLS` = `[TOOL]`（保留数组形状，遍历逻辑不用改）；
  `normToolId()` 归一老 id；`preloadDrafts` 合并前的老草稿按 `savedAt` 取最新一条接手，
  参照图用 `legacyRefsKey` 按老键读一次（`hydrateDraft` 里）。
- `web/app.js`：`IMAGE_KEYS` 加 `generate` 且保留老 key；默认 key 改 generate。
- `cloudflare/src/index.js`：`LEGACY_PAGE["/image"]` → `#generate`。
- `cloudflare/src/routes/image.js`、`app/image_gen/routes.py`：TOOL_NAMES 加
  `generate: "AI 生成"`，老 key 保留（作品库旧记录回显用）。
- `web/image.css`：`.chip` 加 `flex: 0 0 auto; white-space: nowrap;` ——
  中文短语可断行，窄栏里会被 flex 压成「一个字一行」的小方块（原来就这样）。
- `tools/probe_views.mjs`：断言跟上新结构，新增侧栏三项 / 标题 / 上传区文案 /
  空态提示 / 老 hash 归一 等检查。`tools/serve_dev.mjs` 补 `/image` 兼容入口，
  否则本地自检看不到老链接行为。

验证：`node tools/probe_views.mjs --base http://127.0.0.1:8790` **19 条全过**，
无页面 JS 异常。
