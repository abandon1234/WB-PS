### 踩到的坑 / 结论（下次直接照做）

**本机网络：github.com 的 443 被拦，22 通。** 实测 `github.com:443` 超时、
`github.com:22` 与 `ssh.github.com:443`、`api.github.com:443` 通。
所以 **git 只能走 SSH**，HTTPS 推送一律失败（走 http_proxy 127.0.0.1:55778 是 502）。

- GitHub MCP 的 `create_repository` 返回 **403 Resource not accessible by integration**
  （connector token 没建仓权限），建仓只能手工在网页做。
- 装了 GitHub CLI（v2.101.0，`C:\Program Files\GitHub CLI\gh.exe`，**没进 PATH**），
  但 `gh auth login --web` 会失败：OAuth 端点在 github.com 上 →
  `Post "https://github.com/login/oauth/access_token": unexpected EOF`。**gh 在这台机器上用不了。**
- curl 访问 `https://api.github.com` 需要 `--ssl-no-revoke`（代理 MITM，吊销检查过不去），
  但 git push 到 github.com 依然不行，别在这条路上浪费时间。
- 本机没有全局 `~/.gitconfig`，首次提交前设好 `user.name` / `user.email`
  （`abandon1234` + `abandon1234@users.noreply.github.com`）、`core.autocrlf false`。
- SSH 首次连接要先 `ssh-keyscan -t ed25519 github.com >> ~/.ssh/known_hosts`，
  否则报 `Host key verification failed`。密钥 `~/.ssh/id_ed25519` 已生成并交给用户加进账号。
