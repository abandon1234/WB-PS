### 踩到的坑 / 结论

- GitHub MCP 的 `create_repository` 返回 **403 Resource not accessible by integration**
  （connector 的 token 没有建仓权限）。改用 **GitHub CLI** 建仓并推送。
- 环境里原本没有 `gh`，用 `winget install --id GitHub.cli --exact` 装上（v2.101.0），
  装到 `C:\Program Files\GitHub CLI\gh.exe`，**未加入 PATH，要写全路径**。
- 登录走 `gh auth login --web --git-protocol https -s repo,workflow,read:org`，
  会打印设备码 + https://github.com/login/device，需要用户去浏览器点一次授权；
  凭据交给 Git Credential Manager 保存，之后 push 免登录。
- 本机没有全局 `~/.gitconfig`，首次提交前要设 `user.name` / `user.email`
  （用的是 `abandon1234` + `abandon1234@users.noreply.github.com`），并设 `core.autocrlf false`。
