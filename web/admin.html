数据存放说明

  • 中转站配置—
  • API Key只以明文保存在本机配置文件里，任何接口都不会把它下发到前端；后台列表里也只显示打码值。
  • 管理密码以 PBKDF2-HMAC-SHA256（12 万次迭代 + 随机盐）存哈希，登录令牌放 HttpOnly Cookie，前端脚本读不到。
  • 生成结果服务端不保存任何生成图片，图片由浏览器存进本机 IndexedDB，清空浏览器数据即彻底消失。
